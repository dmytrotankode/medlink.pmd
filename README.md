# MedLink PMG Analytics Pro (ПМГ 2026)

Комплексна підсистема пре-білінгу, автономного розрахунку тарифів, ретроспективного аудиту звітів НСЗУ та 2-way зв'язку з електронними медичними записами (ЕМЗ) для МІС «Медлінк» (`evomis`).

---

## 📌 Швидкий старт та головні посилання

| Компонент | Шлях | Опис |
|---|---|---|
| **Головний інтерактивний портал** | [`prototype/index.html`](prototype/index.html) | Мульти-процесний аналітичний центр у стилі Медлінк (всі 6 процесів, вибірки 2 лікарень, 45 колонок, модалки). |
| ⚡ **П1: Пре-білінг лікаря** | [`prototype/process_1_prebilling.html`](prototype/process_1_prebilling.html) | Робоче місце лікаря (`EncounterEdit.vue`), розрахунок ДСГ G01 (24 357 ₴), попередження про відсутність АКПІ. |
| 📥 **П2: Імпорт звіту НСЗУ** | [`prototype/process_2_upload.html`](prototype/process_2_upload.html) | Модуль завантаження OpenXML, симуляція перевірки 4 аркушів, 45 колонок та запуску тарифікації. |
| 📊 **П3: Фінансовий аудит (45 колонок)** | [`prototype/process_3_financial_audit.html`](prototype/process_3_financial_audit.html) | Реєстр розшифровки, автономний розрахунок «Так»/«ГБ»/«Ні», перемикання між 2 лікарнями. |
| ⚠️ **П4: Журнал розбіжностей** | [`prototype/process_4_discrepancies.html`](prototype/process_4_discrepancies.html) | 2-Way звірка за `Encounter.EhealthId`, виявлення втрат на 4.97 млн грн, фільтрація помилок. |
| 🤖 **П5: Асистент виправлення помилок** | [`prototype/process_5_correction.html`](prototype/process_5_correction.html) | Покроковий майстер виправлення кодування, відновлення коштів та черга підписання новим КЕП. |
| 📖 **П6: Довідник нормативів ПМГ** | [`prototype/process_6_catalog.html`](prototype/process_6_catalog.html) | Повний каталог 465 ДСГ, 148 амбулаторних класів та матриць реабілітації АР1–АР4/CR. |
| **Технічне завдання (ТЗ у HTML)** | [`TZ_MedLink_PMG_Analytics.html`](TZ_MedLink_PMG_Analytics.html) | Повне ТЗ у стилістиці MedLink (Quasar/Vue), реєстр процесів з посиланнями, архітектура, моделі EF Core. |
| **Реляційна база даних** | [`pmg_database.sqlite`](pmg_database.sqlite) | **127 МБ**, 285 554 зв'язки діагнозів МКХ-10, 28 167 послуг АКПІ, 465 ДСГ, 148 амбулаторних класів. |
| **Набір тестів (Test Suite)** | [`test_suite/`](test_suite/) | Автоматизовані unit-тести (15 тестів): формули ПМГ-2026, парсинг 4 аркушів НСЗУ, 2-way звірка. |
| **Покрокова документація** | [`docs/`](docs/) | 4 окремі докладні регламенти та специфікації для розробників, економістів та лікарів. |

## 🧪 Запуск тестів (Test Suite)

Для запуску всіх автоматизованих тестів виконайте:

```powershell
python -m unittest discover -s c:\__MEDLINK___\PMG\test_suite -p "test_*.py"
```

Результат:
```
Ran 15 tests in 2.024s
OK
```
