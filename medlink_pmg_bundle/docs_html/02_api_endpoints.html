api 2. Реєстр REST API Ендпоінтів (Проєкт App.Api)

Специфікація контролерів, маршрутів, параметрів запиту та форматів DTO для взаємодії бекенду МІС «Медлінк» з фронтендом Quasar.

cloud_upload Контролер 1: NszuStatementsController (Маршрут: /api/v1/nszu/statements)

Відповідає за прийом файлів звіту НСЗУ, збереження метаданих та управління сесіями імпорту.

POST /api/v1/nszu/statements/upload — Завантаження та потоковий парсинг файлу звіту (.xlsx)
Параметри форми (multipart/form-data):
  • file: IFormFile — файл звіту НСЗУ (.xlsx)
  • organizationId: Guid — ідентифікатор медичного закладу
  • year: int — звітний рік (наприклад, 2026)
  • month: int — звітний місяць (1..12)
Приклад відповіді (JSON 200 OK): 
{
  "statementId": "41a08c45-9ac3-452c-99a1-b6b1f86339b4",
  "fileName": "Вересень 26.xlsx",
  "totalProcessedRows": 5490,
  "acceptedCount": 4980,
  "acceptedRevenue": 24850600.00,
  "rejectedCount": 510,
  "lostRevenue": 2180400.00,
  "importedAt": "2026-10-06T20:15:00Z"
