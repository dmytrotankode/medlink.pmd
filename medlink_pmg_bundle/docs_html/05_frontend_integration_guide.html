web 5. Посібник фронтенд-інтеграції (Vue 2 / Quasar Framework v1.15.3 в App.View)

Покрокова інструкція для розробника МІС «Медлінк» щодо перенесення компонентів прототипу в кодову базу evomis/src/App.View.

folder_copy Крок 1: Розміщення файлів компонентів у каталозі src/App.View

Створіть директорію src/App.View/src/pages/analytics/pmg/ та скопіюйте 8 підготовлених Vue Single-File Components: 

src/App.View/src/pages/analytics/pmg/
├── PmgAuditDashboard.vue             # Головний дашборд аудиту та таблиця 45 колонок
├── PmgReportImport.vue               # Форма завантаження та моніторингу OpenXML-імпорту
├── PmgDiscrepanciesJournal.vue       # Журнал відхилених записів та 2-Way виправлення
├── PmgDoctorsReport.vue              # Звіт у розрізі лікарів та відділень (Аркуш «Звіт»)
├── PmgEncounterPrebillingDialog.vue  # Інтерактивний віджет пре-білінгу для EncounterEdit.vue
├── PmgDsgClassifier.vue              # Каталог 465 стаціонарних ДСГ
├── PmgOutpatientClasses.vue          # Класифікатор 148 амбулаторних класів (Пакет 9)
└── PmgErrorDictionary.vue            # Довідник 186 помилок НСЗУ з алгоритмами усунення

healing Крок 4: Вбудовування віджета пре-білінгу в EncounterEdit.vue

У формі створення/редагування взаємодії (src/App.View/src/pages/medicalEvents/encounter/subpages/EncounterEdit.vue) розмістіть віджет PmgEncounterPrebillingDialog над кнопкою підписання КЕП: 

<!-- Інтеграція пре-білінгу перед кнопкою підписання КЕП -->
<div class="q-my-md">
  <pmg-encounter-prebilling-dialog
    :package="model.packageNumber"
    :main-diagnosis="model.primaryDiagnosisCode"
    :procedures="model.proceduresCodes"
    :patient-age="model.patientAge"
    :is-mountain="userOrganization.isMountain"
    @validation-changed="onPrebillingValidationChanged"
  />
</div>

<script>
import PmgEncounterPrebillingDialog from 'pages/analytics/pmg/PmgEncounterPrebillingDialog.vue';

export default {
  components: {
    PmgEncounterPrebillingDialog
  },
  methods: {
    onPrebillingValidationChanged(status) {
      this.isSigningAllowed = status.isValid;
      if (!status.isValid) {
        this.$q.notify({
          type: 'warning',
          message: 'Увага! Параметри взаємодії не відповідають вимогам ПМГ-2026. Можливе відхилення НСЗУ.'
        });
      }
    }
  }
};
</script>
