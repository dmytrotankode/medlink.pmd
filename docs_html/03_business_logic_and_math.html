calculate 3. Математичний движок розрахунку тарифів (Постанова КМУ №1808)

Формули тарифікації стаціонарних та амбулаторних випадків, алгоритм формування кроків аудиту calculation.steps та нормативна база.

local_hospital 1. Стаціонарна допомога (Пакети 3, 4, 36, 47, 54)

Згідно з Постановою Кабінету Міністрів України №1808, вартість пролікованого стаціонарного випадку визначається за формулою:

Тариф = БазоваСтавка × ВК_ДСГ × К_пакету [× К_гірський (1.25)]
  • Базова ставка (BaseRate): 8 735,00 ₴ (зафіксована в таблиці dsg_tariff_setting.base_rate).
  • ВК_ДСГ (WeightCoef): Ваговий коефіцієнт складності ДСГ (з довідника dsg_group_weight, 471 група). Діапазон: від 0.20 до 18.50.
  • К_пакету (PackageSpecificCoef):
    • 0.55 — терапевтичний профіль (Пакет 3), хіміотерапія (Пакет 47), стаціонарна реабілітація (Пакет 54).
    • 0.60 — хірургічні втручання (Пакет 4). При тривалості перебування ≤ 3 діб застосовується правило короткої тривалості (PK-01A).
  • К_гірський (MountainCoef): 1.25 (+25% до тарифу згідно із Законом України «Про статус гірських населених пунктів»).
medical_services 2. Амбулаторна вторинна допомога (Пакет 9)
Тариф = БазоваСтавка_АМБ (155,00 ₴) × Коефіцієнт_Класу (К)

Вартість випадку амбулаторної допомоги визначається віднесенням виконаних медичних втручань до одного зі 148 амбулаторних класів. Коефіцієнт варіюється від 1.00 (стандартна консультація, 155.00 ₴) до 9.80 (КТ з контрастом, 1 519.00 ₴).

code Імплементація калькулятора PmgTariffCalculatorService.cs 
using System;
using System.Collections.Generic;
using System.Text.Json;
using App.Domain.Models.dsg;

namespace App.Business.Services.Pmg
{
    public class PmgTariffCalculatorService : IPmgTariffCalculatorService
    {
        private const decimal InpatientBaseRate = 8735.00m;
        private const decimal OutpatientBaseRate = 155.00m;
        private const decimal MountainMultiplier = 1.25m;

        public CalculationOutput CalculateInpatient(
            string dsgCode, 
            decimal weightCoef, 
            int packageNumber, 
            bool isMountain,
            int stayDays)
        {
            var steps = new List<CalculationStepDto>();

            // Крок 1: Базова ставка
            decimal runningTotal = InpatientBaseRate;
            steps.Add(new CalculationStepDto {
                Code = "BASE",
                Caption = "Базова ставка за Постановою №1808",
                Value = InpatientBaseRate,
                Operation = "=",
                RunningTotal = runningTotal
            });

            // Крок 2: Ваговий коефіцієнт ДСГ
            runningTotal *= weightCoef;
            steps.Add(new CalculationStepDto {
                Code = "PK-12",
                Caption = $"Ваговий коефіцієнт ДСГ {dsgCode}",
                Value = weightCoef,
                Operation = "×",
                RunningTotal = Math.Round(runningTotal, 2),
                NormativeReference = "Вагові коефіцієнти ДСГ (RD-13)"
            });

            // Крок 3: Специфічний коефіцієнт пакету
            decimal packageCoef = (packageNumber == 4) ? 0.60m : 0.55m;
            runningTotal *= packageCoef;
            steps.Add(new CalculationStepDto {
                Code = "SHARE",
                Caption = $"Частка глобальної ставки ({packageCoef:F2})",
                Value = packageCoef,
                Operation = "×",
                RunningTotal = Math.Round(runningTotal, 2)
            });

            // Крок 4: Гірський коефіцієнт
            if (isMountain)
            {
                runningTotal *= MountainMultiplier;
                steps.Add(new CalculationStepDto {
                    Code = "PK-04",
                    Caption = "Гірський коефіцієнт 1,25 (+25%)",
                    Value = MountainMultiplier,
                    Operation = "×",
                    RunningTotal = Math.Round(runningTotal, 2),
                    NormativeReference = "Закон України «Про статус гірських населених пунктів»"
                });
            }

            return new CalculationOutput
            {
                TotalTariff = Math.Round(runningTotal, 2),
                BaseRate = InpatientBaseRate,
                WeightCoef = weightCoef,
                DsgCode = dsgCode,
                CalculationJson = JsonSerializer.Serialize(new { steps, total = runningTotal })
            };
        }
    }
}
